Privacy

Rehab Tracker, a personal single user app. Last updated 20 September 2026.

What this app is

A private rehab and training log built and used by one person. It is not a product, it is not distributed, and it has no other users, no accounts and no sign up.

Where the data lives

  • Everything is stored on the owner's own devices and in a private repository that only the owner can read, which the devices use to stay in step.
  • There is no server run by anyone else, no analytics, no advertising, no tracking and no third party sharing.
  • Nothing is sold, and nothing is used to train anything.

Connected services

  • When the owner connects a wearable or health service, the app reads that service's data for the owner's own account only, using access the owner grants and can revoke at any time in that service's settings.
  • Access credentials are kept on the owner's own computer and are never published.
  • The app only reads. It does not write anything back to a connected service.

Deleting it

Revoking access in the connected service stops all reading immediately. Deleting the app's data on the owner's devices and the private repository removes the copy held here.
